A plain text site is a constraint, and the constraint is the point. When a page is made of nothing but words, you have to write words that are worth reading. There is nowhere to hide.

“The simplest thing that works is the thing that keeps working.”

Links go in style.css colours, lists are plain, code blocks are indented with a rule on the left:

cd rosemaryavenue.github.io
$EDITOR posts/my-new-post.html
git add posts/my-new-post.html writing.html
git commit -m "New post: my new post"
git push
