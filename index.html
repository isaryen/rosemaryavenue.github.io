Welcome

This is a plain text website. It is a single stylesheet, a handful of HTML files, and nothing else. No images, no webfonts, no JavaScript, no analytics, no build step. It renders the same in a browser, in lynx, and on paper.

Replace the placeholder text below with your own. Every page on this site is a copy of template.html — edit the title, the nav, and the body, then save it as a new file.

What is here

  • writing — a list of posts, newest first
  • about — who you are, in your own words
  • contact — how to reach you
  • 404 — the page you land on when a link goes dead

Rules of the house

  1. Text first. If a page cannot be read in a terminal, it is too complicated.
  2. One stylesheet. Add to style.css rather than writing inline styles.
  3. No tracking, no cookies, no third-party scripts.
  4. Short pages. A page that scrolls forever is a page nobody reads.

Getting started

git clone https://github.com/isaryen/rosemaryavenue.github.io.git
cd rosemaryavenue.github.io
make serve        # http://localhost:8080

Then edit index.html, commit, and push to main. GitHub Pages will publish it. See README.md for the full instructions.
